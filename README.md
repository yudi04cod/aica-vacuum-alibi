One funny line for make.fun's "The Vacuum's Alibi: One Line, 200
Characters": the excuse a robot vacuum gives for missing a spot, in a
single sentence of at most 200 characters — deadpan, a little smug about
its sensors, with the punch at the end.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
sentence, 1–200 characters), and writes the same bytes on every run.
